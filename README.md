​Qué hace este proyecto

Lo que hace la vitrina de servicios es básicamente guardar servicios y administrarlos, donde se les puede modificar, eliminar y agregar, además de crear nuevos usuarios. 

​Stack técnico

Django + MySQL (Aiven) + Tailwind CSS + Render

​Cómo se prueba el aislamiento por usuario

Cree dos usuarios, Lo-77 y Usuario_B respectivamente, los registre y cada uno registro servicios diferentes, estos mismos no se mezclan cuando entras a la otra cuenta, despues, desde otra cuenta saque la id de un registro y trate de entrar a ese registro de ese servicio de la otra cuenta mediante otra cuenta, pero salio un 404 page no found como debería ser.
